HOW IT WORKS

AI 组织表达，
程序负责渲染与检查。

输入可以是系统描述、经 Agent 阅读的代码，或已有 Mermaid。图中每个节点和关系最终都落到结构化规格里。

  1. 01

    理解与取舍

    Agent 选择图型、关键组件、主链路和布局意图。

  2. 02

    形成图规格

    把节点、关系、边界和布局写入有类型约束的 JSON。

  3. 03

    渲染并校验

    专用渲染器生成 HTML / SVG；错误带着具体对象与修复提示返回。

  4. 04

    交互阅读与交付

    检查通过才替换最终文件，浏览器负责查看、探索和导出。

这里展示的是什么

“本仓库实战”是根据 0909_codex_project 实际源码整理的中文架构图，带有 14 处固定提交的源码引用。其余六个图来自上游样例，保留英文节点与说明；全部由真实 Archify 渲染器生成。

真实案例中的关系由本次代码阅读后编写，程序核验源文件与行范围、检查结构与布局；这不等于独立完成代码理解，也不直接证明运行影响。阅读过程与证据 ↗

与我们研究过的 Lieflat Charts ↗ 相比：它侧重数据、指标和报告；Archify 侧重系统、关系与过程。
