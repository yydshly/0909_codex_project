# 真实场景素材：GitHub 项目研究室

这是本工作区正在使用的项目研究流程，面向初次加入研究室的协作者。本次将文字规范转成一张封面和三张手绘解释图。

## 原始材料摘录

README.md：持续研究遇到的优秀开源项目，记录它们解决的问题、实现思路、运行方法和可复用的经验。每个项目独立整理研究笔记、截图和可选的 Web 演示，这里只保留摘要与入口。

docs/project-guide.md：完成后填写项目 README，记录研究对应的上游版本或 Commit。实验代码放在 experiments/，演示放在 web/。引入上游源码时保留许可信息。项目清单保存编号、名称、来源、一句话摘要、状态、标签、封面和演示开关。

docs/deployment.md：资料推送与站点上线是独立步骤。当前采用手动发布；修改网页并推送后，需要执行发布流程。普通提交和拉取请求校验项目清单、README 同步状态、脚本测试和静态构建。

## 页面取舍

- 封面：用研究工作台连接原始项目与整理后的知识资料。
- 第 1 页：只讲清楚收录档案包含来源、版本、许可和摘要。
- 第 2 页：将阅读资料、理解结构和演示验证组织成三站流程；这是针对现有研究目标的教学编排，不声称每个项目都已完成运行验证。
- 第 3 页：强调保存资料与发布网站是两个操作，避免把提交检查误认为网站已经更新。

材料快照日期：2026-09-09。没有使用虚构业务指标或客户案例。
