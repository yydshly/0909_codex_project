关于统计口径与复用条件

本页按 2026-09-09 核对的固定提交统计：58 个顶层 SKILL.md + 5 个嵌套 SKILL.md = 63 个文件入口。「孙割」为「孙宇晨」的别名。入口之间也存在重叠，文件数不等于独立能力数。上游 README 标注 57，本页采用文件树口径。

「方法可复用」指主要依赖宿主 Agent 和文档；「需工具配置」指需要模型、服务或本地工具；「需工作台适配」指明显依赖作者的目录、模板、身份或配套系统。分类是研究判断，均不代表已经安装或运行成功。

WHERE IT FITS

从日常任务，理解使用场景。

01 / 内容生产

自媒体与课程教程

选题、改稿、配音字幕和图文排版相互配合，准备文章、讲解视频及教程素材；按实际需要选择制作环节。

02 / 产品与业务

产品演示与商业分析

用产品动效和讲解脚本制作演示素材，用目标澄清、对标与模拟讨论整理分析和决策参考。

03 / 持续工作

内容资产与制作管理

整理素材、保存状态、交接质检和数据复盘，让前一步的产物能够继续加工。完整流程需要适配工作目录及服务配置。
